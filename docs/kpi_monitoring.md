# TITAN KPI 모니터링

모니터링은 전략을 자동 변경하지 않는다. 저장된 선정 검증 결과를 읽어
성과 저하 가능성을 표시하는 운영 안전장치다.

```powershell
python -m app.main monitor
```

결과는 `output/monitoring`의 JSON 스냅샷과
`output/reports/kpi_monitoring.md` 보고서로 저장된다.

## 판정 단위

- 5·10·20·40일 보유기간을 각각 독립적으로 판정한다.
- 각 보유기간의 최근 10개 검증 실행을 최근 구간으로 사용한다.
- 최근 구간 이전 기록을 겹치지 않는 기준 구간으로 사용한다.
- 최근·기준 구간 모두 30종목 이상이어야 상태 판정을 활성화한다.
- 표본 부족은 `INSUFFICIENT_DATA`이며 상태는 `NORMAL`을 유지한다.

## 기본 상태 규칙

- `WATCH`: 승률이 기준 대비 8%p 이상 하락하거나 초과수익률이 1.5%p
  이상 하락
- `ALERT`: 승률이 15%p 이상 하락하거나 초과수익률이 3%p 이상 하락
- 최근 승률 40% 미만과 최근 초과수익률 -3% 미만을 동시에 충족해도
  `ALERT`

임계값은 `MonitoringPolicy`에 명시되어 있으며 전략 점수나 종목 선정
기준과 분리된다. 상태가 `ALERT`여도 전략은 자동 수정되지 않으며,
원인 분석과 Walk-forward 재검증을 거쳐야 변경 후보가 될 수 있다.

보고서에는 누적·최근 수익성과 함께 Context, Feature, 점수 구간,
일일 운영 실패율이 포함된다.
